Acerca de este proyecto

Actividad Sumativa — Unidad 2, Arquitectura de Aplicaciones Web. CRUD de Productos con backend Spring Boot y frontend Angular.

Lo que se desarrollo

La parte tecnica del proyecto — lo que no se ve directamente en pantalla, pero sostiene todo lo que si se ve.

Backend

  • API REST con Spring Boot 3 + Spring Data JPA (Hibernate) + PostgreSQL.
  • CRUD completo de Producto: crear, listar, obtener por id, actualizar, eliminar.
  • Manejo centralizado de errores (404, 400 de validacion, 400 de tipo invalido, 500 generico) con cuerpo JSON consistente.
  • CORS configurado con origen permitido configurable por variable de entorno.
  • Endurecimiento de seguridad: sin password por defecto en la base de datos, mensajes de error 500 sanitizados (no exponen detalles internos).

Frontend

  • Angular con standalone components y signals (sin NgRx, sin NgModules).
  • Angular Material como base funcional (tabla, formularios, dialogos, toasts).
  • Sistema de diseno propio: tokens de color/tipografia/espaciado, modo oscuro con acento cian, tipografia Space Grotesk + Inter.
  • Formularios reactivos con validacion (nombre, descripcion, precio).
  • Interceptor HTTP centralizado para notificar errores del backend como toasts.
  • Diseno responsive (mobile, tablet, escritorio).
  • Guard de rutas con inicio de sesion (usuario/contrasena de demostracion).
  • Paleta de graficos validada para contraste y daltonismo (herramienta de validacion de accesibilidad de color).

Lo que se muestra

La parte visual — lo que efectivamente se ve e interactua al usar la aplicacion.

  • Inicio de sesion con validacion de credenciales antes de entrar a la aplicacion.
  • Dashboard con tarjetas de estadisticas (total de productos, valor del inventario, precio promedio) con animacion de conteo y efecto de inclinacion 3D al pasar el mouse.
  • Graficos de ranking de productos por precio y de distribucion por rango de precio.
  • Bordes animados con luz en movimiento en las tarjetas del dashboard.
  • Listado de productos en tabla ordenable, con busqueda en tiempo real por nombre.
  • Formulario de creacion y edicion con validacion visual inmediata.
  • Confirmacion antes de eliminar un producto, para evitar borrados accidentales.
  • Notificaciones (toasts) de exito y error con estilo propio.
  • Transiciones animadas al navegar entre pantallas.
