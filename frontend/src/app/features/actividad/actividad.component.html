Arquitectura de Aplicaciones Web — Unidad 2

Backend con servicios RESTful CRUD sobre base de datos usando un framework

Indicador de logro

Construir una aplicacion web con la implementacion de una API REST para facilitar el intercambio de informacion de forma segura.

Que pide la actividad

  • Crear una entidad Producto con los atributos id, nombre, descripcion y precio.
  • Implementar los endpoints RESTful para gestionar Producto con las 4 operaciones CRUD.
  • Usar un ORM (como Hibernate) para el modelo y las operaciones con la base de datos, sin escribir SQL manual.
  • Usar una base de datos local o en la nube (cuenta gratuita).
  • Aplicar manejo adecuado de errores en los servicios.
  • Subir el codigo a un repositorio personal en GitHub.

Condiciones de la entrega

Un video explicativo de maximo 15 minutos que muestre:

  • El paso a paso de la construccion de la aplicacion, narrado.
  • El funcionamiento de los servicios REST (CRUD) probados con Postman, Swagger o Insomnia.
  • Las operaciones para subir el codigo a GitHub.
  • La URL del repositorio y el codigo fuente alojado.
